## Overview

Tunnels forwards ports through your servers so you can reach services that are not exposed.

Read the [docs](https://docs.termix.site/plugins/tunnels) to set it up and use it.

<br />

## Features

- Local, remote and dynamic SOCKS5 forwarding
- Reconnects on its own when a tunnel drops
- Start tunnels on boot
- Route a tunnel through a second host
- WireGuard gateways that forward public ports to services on a private host
- Finds listening ports on its own, with a switch for each one
- Client tunnels on your own computer from the desktop app, with presets you can save to the server

## Support

Bugs and ideas for Tunnels go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Tunnels/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Tunnels/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
